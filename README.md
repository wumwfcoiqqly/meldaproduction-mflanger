## Overview

MeldaProduction MFlanger offers through-zero flanging, barberpole sweep, and standard analog flanging with detailed modulation and stereo control.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **MeldaProduction MFlanger** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Through-Zero** | Accurate through-zero flanging for the classic jet-flange sound |
| **Barberpole** | Continuously rising or falling flange with no direction reset |
| **Stereo Mode** | Independent left/right modulation for wide stereo flanging |
| **Free Tier** | Core functionality available free from MeldaProduction |
